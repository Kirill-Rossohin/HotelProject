# HotelProject
HotelProject - консольное приложение для управления гостиницей. Система предназначена для автоматизации процессов контроля за состоянием номерного фонда, учета бронирований, заселения и выселения гостей. В системе отслеживаются гостиничные номера, клиенты и факты бронирования/проживания. В системе учитываются: номерной фонд гостиницы, типы номеров и их вместимость, бронирования, заселение и выселение гостей и статусы номеров. Система повышает скорость обслуживания клиентов при регистрации и бронировании комнат и в разы уменьшает вероятность совершить ошибку (например, двойное бронирование одного номера), потому что доступ к актуальному статусу номеров(свободен/занят) есть всегда.

### Пользователи системы
В этой системе есть всего две роли: клиент (гость) и администратор. Клиент может бронировать номера, а у администратора есть возможность управлять номерами своей гостиницы и регистрировать других администраторов (и вместе с ними новую гостиницу, принадлежащую новому администратору). 

### Основные функции
Система даёт возможность:
* регистрировать клиентов.
* регистрировать администраторов.
* авторизовать пользователей.
* управлять пользователями.
* управлять номерами своей гостиницы.
* добавлять в какую-либо гостиницу новый номер.
* убирать из гостиницы номер.
* изменять вместительность старых комнат. 
* управлять бронированием.
